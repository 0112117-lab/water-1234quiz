# FUTURE_ROADMAP.md — 정수퀴즈 향후 개선 로드맵

> 단일 HTML 웹앱이라는 성격(빌드 없음·서버 없음)을 유지하는 선에서의 개선안.
> 우선순위는 "학습 효과·안정성 → 편의 → 확장" 순. 각 항목은 제안이며 확정 계획이 아님.

---

## P0 — 안정성/신뢰 (먼저)

1. **앱 버전 표기 내장**
   - 현재 코드에 버전 문자열 없음. 설정 화면 하단에 `v날짜/번호` 표시.
   - 효과: 사용자가 최신본 반영 여부를 스스로 확인(로컬/라이브 혼동 방지).
2. **복원(import) 입력 검증 강화**
   - 예상 키(exams/marks/wrongHist/best/last/openParts)만 반영하는 화이트리스트.
3. **자동 백업 리마인더**
   - 일정 학습량마다 "백업 권장" 토스트 1회. (localStorage 유실 대비)
4. **오프라인 캐싱(선택):** 서비스워커 도입 검토.
   - 단, SW는 별도 파일이 필요해 "단일 파일" 원칙과 상충 → 도입 시 파일 2개 체계로 전환할지 결정 필요.

## P1 — 학습 효과

5. **틀린 문제 우선 복습(간격 반복)**
   - `wrongHist` 활용해 오답 빈도 높은 문제부터 재출제.
6. **과목별/회차별 정답률 통계 강화**
   - 약점 과목 시각화(막대). 외부 라이브러리 없이 순수 CSS/SVG로.
7. **오답 원인 태그**
   - 문항에 개념 태그를 달아 취약 개념 묶어보기.
8. **시험 모드(모의고사)**
   - 80문항 타이머 + 최종 채점(중간 정답 비공개) 옵션.

## P2 — 편의/UX

9. **검색/필터**: 키워드로 문항 검색, 북마크/오답 필터.
10. **글자 크기·다크/라이트 토글**: 접근성.
11. **진행 이어보기 개선**: 파트별 마지막 위치 각각 기억(현재는 전역 `S.last` 1개).
12. **결과 공유 카드**: 점수 이미지를 저장(캔버스). 개인정보 없음.

## P3 — 콘텐츠/확장

13. **문항 데이터 분리 관리**: 편집 편의를 위해 데이터를 별도 JSON으로 뺄지 검토(단, 단일 파일 원칙과 상충 → 트레이드오프 결정).
14. **1급 회차 등 콘텐츠 확장**: 동일 데이터 규격으로 회차 추가.
15. **해설 품질 향상**: 계산·법규 문항 해설 보강, 불확실 정답(`교재 정답표 기준`) 재검증.

## 결정이 필요한 트레이드오프

| 주제 | 유지(단일 파일) | 전환(다중 파일) |
|---|---|---|
| 배포 단순성 | 파일 1개만 업로드, 매우 단순 | 여러 파일 관리 필요 |
| 오프라인 캐싱(SW) | 불가(SW는 별도 파일 필요) | 가능 |
| 데이터 편집 | 큰 단일 파일 편집 부담 | JSON 분리로 편해짐 |
| 파일 크기 | 문항 증가 시 계속 증가 | 분리로 완화 |

**권고:** 당분간 **단일 파일 유지**(운영이 가장 단순). 오프라인 캐싱이나 데이터 편집 부담이 실제 문제로 커질 때 다중 파일 전환을 재검토.

## 유지 원칙 (개선 시에도 지킬 것)

- `localStorage` 키 `jsq_v1` 및 문항 `g`(group key) 안정성 유지(사용자 기록 보호).
- 외부 트래커·광고·개인정보 수집 도입 금지(현재의 프라이버시 강점 유지).
- 새 기능도 서버 없이 클라이언트에서 완결되도록.
