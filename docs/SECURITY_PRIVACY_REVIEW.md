# SECURITY_PRIVACY_REVIEW.md — 정수퀴즈 보안·개인정보 검토

- **대상:** 정수퀴즈 단일 HTML PWA (`index.html`)
- **아키텍처 전제:** 서버·백엔드·DB **없음**. 100% 클라이언트 사이드. GitHub Pages 정적 호스팅.
- **검토 성격:** 코드/구조 기반 자체 점검. 법적·규제 준수의 확정 판단은 아님(필요 시 전문가 확인).

---

## 1. 데이터 수집·저장

| 항목 | 내용 |
|---|---|
| 수집하는 개인정보 | **없음** (이름·이메일·전화·위치·기기ID 수집 코드 없음) |
| 저장 위치 | 사용자 브라우저 `localStorage` 키 `jsq_v1` (기기 로컬만) |
| 저장 내용 | 학습기록(응답, 오답횟수, 북마크, 연속정답 기록, 마지막 학습 위치) |
| 서버 전송 | **없음** (수집·업로드하는 네트워크 코드 없음) |
| 쿠키 | 사용 안 함 |
| 애널리틱스/트래커 | 없음 |
| 광고 | 없음 |

**평가:** 개인정보 수집·전송이 없어 개인정보 관점의 위험은 낮음. 학습기록은 전적으로 사용자 기기에만 존재.

## 2. 외부 통신(Network) 표면

- **CDN/외부 스크립트:** 없음(모든 코드 인라인, 시스템 폰트 사용) → 서드파티 스크립트 공급망 위험 없음.
- **외부로 나가는 경우:** 사용자가 "AI에게 질문하기"를 눌러 **클로드/ChatGPT로 이동**할 때만.
  - 이동 시 **문제 프롬프트는 클립보드에 복사**될 뿐, 앱으로 자동 전송되지 않음(사용자가 붙여넣어야 함).
  - GPT는 지정 공유 링크로 연결.
- **매니페스트/아이콘:** data URI로 내장 → 외부 요청 없음.

## 3. XSS / 콘텐츠 주입

- 문제·보기·해설은 **프로젝트가 소유한 정적 데이터**(사용자 입력이 화면에 렌더되지 않음).
- `esc()` 함수로 `& < >` 이스케이프 처리 존재.
- **복원(importData) 경로 주의:** 사용자가 붙여넣은 JSON을 파싱해 상태로 사용. 붙여넣기 대상은 본인 백업이므로 위험은 낮으나, 파싱 실패 시 안전 처리(형식 오류 토스트) 확인 권장. **eval 대신 JSON.parse 사용 유지 필수.**

**권고:** import 시 `JSON.parse`만 사용(현재 방식 유지), 구조 검증(예상 키만 반영) 추가 시 견고성 향상.

## 4. 인증·권한

- 로그인·계정·권한 개념 없음(익명 로컬 학습). 인증 취약점 표면 없음.

## 5. 호스팅·배포 보안

- GitHub Pages는 **https** 제공 → 전송 구간 암호화.
- 정적 파일만 배포, 서버 실행 코드 없음 → 서버 사이드 취약점 없음.
- **공개 저장소 여부 확인 권장:** 저장소가 public이면 소스가 공개됨(학습 콘텐츠 저작권은 별도 검토 필요, 아래 6번).

## 6. 콘텐츠·저작권 (개인정보와 별개, 유의)

- 문항이 교재/기출을 기반으로 하는 경우, **저작권·이용범위**는 개인 학습용과 공개 배포가 다를 수 있음.
- 공개 URL로 배포 중이므로, 원저작물 권리관계는 별도 확인 권장. (법적 판단은 전문가 확인 필요 — 이 문서는 확정이 아님)

## 7. 위험 요약

| 위험 | 수준 | 근거 |
|---|---|---|
| 개인정보 유출 | 낮음 | 수집·전송 코드 없음 |
| 서드파티 공급망 | 낮음 | 외부 스크립트/CDN 없음 |
| XSS | 낮음 | 정적 데이터 + esc 처리, JSON.parse 사용 |
| 데이터 유실 | 중간 | localStorage 의존 → 브라우저 데이터 삭제 시 기록 소실(백업 기능으로 완화) |
| 저작권 | 확인 필요 | 공개 배포 + 교재 기반 콘텐츠 |

## 8. 권고 조치

1. **키 안정성:** `jsq_v1` 키를 함부로 바꾸지 말 것(사용자 기록 유실). 스키마 변경 시 마이그레이션 코드 동반.
2. **백업 유도:** 설정의 백업 기능을 사용자에게 주기적으로 안내(데이터 유실 완화).
3. **import 방어:** 복원 시 예상 키만 반영하는 화이트리스트 검증 추가 검토.
4. **저작권 확인:** 공개 배포 콘텐츠의 권리관계 점검(전문가 확인).
