# APP_SPEC.md — 정수퀴즈 기능·명세서

- **대상 앱:** 정수퀴즈 (단일 HTML PWA, `index.html`)
- **플랫폼:** 모바일/데스크톱 브라우저 (Android 삼성인터넷·크롬 / iOS Safari / PC 브라우저)
- **기준 코드:** 이 세션의 `index.html` (총 문항 2,038)

---

## 1. 목적

정수시설운영관리사 시험 대비용 문제풀이 학습 앱. 과년도 기출 + 적중예상문제를 스마트폰에서 앱처럼 반복 학습한다. 서버 없이 브라우저 로컬 저장만 사용한다.

## 2. 기술 스택

| 항목 | 내용 |
|---|---|
| 언어 | HTML5 / CSS3 / Vanilla JavaScript (ES6+) |
| 프레임워크 | 없음 |
| 빌드 | 없음 (파일 하나로 실행) |
| 외부 의존성 | 없음 (CDN 미사용, 시스템 폰트 사용) |
| 저장소 | 브라우저 `localStorage` (키 `jsq_v1`) |
| 배포 | GitHub Pages (`0112117-lab/water-1234quiz`) |

## 3. 화면 구성

1. **홈(`goHome`)**
   - 히어로 배너(진행률/최고 연속정답)
   - **이어풀기 카드** — 마지막 학습 지점 또는 다음 미완료 장으로 이동
   - **파트별 접이식 목록** — 1권 / 2권 / 3권 / 과년도 기출
2. **시험 메뉴(`examMenu`)** — 회차/장 선택 시: 이어서 풀기·처음부터·과목별·셔플·오답노트·북마크
3. **문제 화면(`renderQ`)** — 문제·보기·별표(북마크)·해설·이전/다음·번호 점프
4. **결과(`showResult`)** — 점수·정답률
5. **통계(`showStats`)** — 학습 현황
6. **설정(`showSettings`)** — 백업/복원·홈 화면에 추가·초기화

## 4. 핵심 기능 명세

### 4.1 풀이 모드 (`startQuiz(key, mode, subjIdx)`)
| mode | 동작 |
|---|---|
| `resume` | 첫 미응답 문항으로 이동(없으면 1번) |
| `restart` | 해당 회차 응답 초기화 후 1번부터 |
| `subject` | 과목별 필터(수처리공정/수질분석및관리/설비운영/수리학) |
| `shuffle` | 문항 순서 무작위 |

### 4.2 이어풀기 (홈 카드)
- `S.last.key` 회차에 미응답이 있으면 → 그 회차를 그 번호부터 이어서.
- 그 회차를 **다 풀었으면 → 목록 순서상 다음 미완료 장으로 자동 이동** (예: 3장 완료 → 4장).
- 뒤쪽에 미완료가 없으면 앞쪽에서 탐색, 전부 완료면 "다시 보기(1번부터)".

### 4.3 응답 채점 (`pick` → `setAns`)
- 보기 선택 시 즉시 정오 표시 + 해설 노출.
- 오답 시 `wrongHist[qid]` 카운트 증가.
- 정답 시 연속정답(streak) 갱신 및 `best` 최고기록 저장, 시각 효과(`burst`).

### 4.4 오답노트 / 북마크
- **오답노트(`startWrong`)**: 한 번이라도 틀린 문항 모음.
- **북마크(`startMarked`)**: 별표(`toggleMark`)한 문항 모음, `S.marks`에 `qid` 저장.

### 4.5 백업 / 복원
- **내보내기(`exportData`)**: 학습기록(S) JSON을 클립보드로 복사.
- **복원(`importData`)**: 붙여넣은 JSON으로 상태 복구.
- **초기화(`resetAll`)**: 확인 후 전체 기록 삭제.

### 4.6 AI 질문하기 (`askAI` → `openAI`)
- 문제/보기/정답/내가 고른 답을 정해진 프롬프트로 **클립보드 복사**.
- 모달에서 클로드 또는 ChatGPT 선택:
  - **Android:** `intent://` (패키지 `com.anthropic.claude` / `com.openai.chatgpt`)로 앱 직접 실행, 미설치 시 `browser_fallback_url`로 웹.
  - **iOS:** 유니버설 링크(https)로 이동(앱 설치 시 앱, 아니면 웹).
  - **PC:** 새 탭으로 웹.
- GPT 대상 URL: 지정 공유 링크 `https://chatgpt.com/share/6a3b8f68-a760-83ee-8f3c-158d2337954d`.

### 4.7 홈 화면에 추가 (`addHome`)
- `beforeinstallprompt` 이벤트를 잡아 두었다가 설치 프롬프트 실행.
- 자동 설치 불가 시 브라우저별 수동 안내(삼성인터넷 메뉴 / iOS 공유 버튼).
- 이미 스탠드얼론(설치 상태)이면 안내 토스트.
- 매니페스트·아이콘·apple-touch-icon은 `<head>`에 data URI로 내장.

## 5. 데이터 명세

- 배열 `QUESTIONS`, 각 원소 필드: `g, gt, s, n, q, c[4], a(1~4), e`.
- 삽입 마커 `/*__DATA__*/` 앞에 신규 문항 추가.
- 무결성 규칙: 회차별 n은 1~80 완전(누락·중복 없음), a는 1~4, 모든 필드 존재.

## 6. 비기능 요구사항

- **오프라인 우선:** 최초 로드 후 데이터는 파일 내장이라 네트워크 없이 문제풀이 가능(단, AI 링크·설치는 온라인/https 필요).
- **성능:** 단일 파일 ~1.14MB. 최초 로드 시 전체 파싱. 문항 증가 시 파일 크기 선형 증가에 유의.
- **접근성:** 큰 탭 타깃, 다크 테마 대비. (개선 여지는 로드맵 참고)
